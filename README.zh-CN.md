# ScadLatch

**点选一个面，添加新结构，保留原来的参数。**

ScadLatch 面向这样的 3D 打印用户：已经找到一个有用的 OpenSCAD 模型，但原作者没有提供自己需要的修改选项，也不想为了这次修改学习整段代码。

在本机浏览器中打开现有 `.scad`，选择受支持的平面，添加圆孔或矩形开口，并把修改写回可编辑的源程序。之后改变原模型的尺寸，新结构会跟随选中的面。最终保存修改后的 SCAD，以及由真实 OpenSCAD 引擎生成的 STL。

## 它解决什么事

例如，你下载了一个可调尺寸的外壳，希望侧面多一个出线口，但现有参数中没有这个选项。

操作流程：

1. 打开一个自包含的 SCAD 文件。
2. 选择需要修改的面；如果模型中有多个相同部件，明确选择其中一个实例。
3. 选择圆孔或矩形开口，设置位置和尺寸。
4. 检查重新生成的实体，再改变原模型的尺寸，确认开口仍贴合预期位置。
5. 保存 SCAD 和 STL；需要回到 ScadLatch 继续编辑时，另存 `.scadlatch.json` 工程。

修改保留原来的几何构造和参数表达式。选中的外表面跟随原尺寸变化，开口大小保持指定的毫米数。面内位置遵循明确的规则：

| 选中的实体 | 开口中心的位置规则 |
| --- | --- |
| `cube()` | 距两条低坐标边的毫米偏移保持不变 |
| `hull()` 或 `linear_extrude()` | 相对该实体原始局部原点的坐标保持不变；允许负值 |

两种规则都不会在尺寸变化后自动居中。明确写出的模块调用具有不同的编辑路径，因此只选择一个部件时，不会把同一个孔加到所有相同部件上。

## 与已有办法的关系

参数面板适合调整作者预留的选项。网格编辑器适合修改固定形状。现有可视化 CSG 工具可以搭建基本体与布尔结构；PurCad 等 AI 工具也已经可以修改已有 SCAD 并导出源码。

ScadLatch 专注于这条修改流程：**点选已有部件，添加原作者没有提供的新结构，继续使用原有参数。** 当前支持下列形式，不替代通用 CAD 编辑器。

## 首版范围

- 输入为一个自包含的 OpenSCAD 文件。
- 修改对象是受支持的 `cube()`、完整 `hull()` 实体和完整 `linear_extrude()` 实体。所选面必须外露、平坦、与实体局部坐标轴对齐，并处于该实体局部包围盒的最小或最大边界。曲面、斜面和内凹台阶不能直接选择。
- 新增圆孔或矩形开口。
- 输出修改后的 SCAD、由 OpenSCAD 编译的 STL，以及可继续编辑的 ScadLatch 工程。
- 明确写出的多个模块调用能够区分实例；暂不支持循环生成的重复实例编辑。
- 暂不支持复杂库、`include`/`use` 依赖和外部导入素材，也不承诺编辑任意 SCAD 程序。
- 凸包和拉伸体作为整体编辑，保留内部构造；其中的基本体不能单独选面。暂不支持对 `minkowski`、`intersection`、`offset` 轮廓、扭转拉伸及非均匀缩放直接编辑。背景模型和布尔运算的减去部分也不是可选实体。
- 开口必须位于实体的局部包围盒以内。凹形实体的包围盒可能包含空白区域，需要检查实际切削，包括只切到部分材料的情况。界面会提示未移除可测材料的开口；无效编辑和生成失败会保留最后一次成功的模型。
- 未知模块、函数、变量及无效几何参数会阻止生成，不会把 OpenSCAD 勉强生成的部分模型当作完整结果。
- 正数深度从所选外表面向内计算，凹形实体也遵循同一平面；不会从已有孔的底部继续计算。贯穿切削跨过整个选中实体，可能同时打开对面的墙。
- 请保存工程以继续选面编辑。导出的 SCAD 用于 OpenSCAD，暂不支持将其中生成的代码重新作为 ScadLatch 原始模型导入。
- 编译成功不代表可打印、合身或满足强度要求。实际制作前需要检查尺寸和切片结果。

不能直接编辑的结构会得到说明。模型能够编译不代表其中一定有可编辑面。这是本机工作台，不应把服务端暴露为公共网络渲染服务。

## 启动

应用使用浏览器界面和本机 Node.js 服务，由服务调用原生 OpenSCAD 命令行引擎，不依赖在线模型 API。

需要 **Node.js 22 或更新版本**。在项目目录运行：

```sh
npm install
npm run setup
npm run dev
```

访问 `http://127.0.0.1:4173`。Windows 的 setup 会寻找已有 OpenSCAD，或下载约 22 MB 的官方 OpenSCAD 2021.01 便携版。macOS 和 Linux 请先安装 OpenSCAD，或通过 `OPENSCAD_BIN` 指定可执行文件，再运行 setup。干净 Windows 安装已经独立复现；macOS/Linux 安装及浏览器兼容范围尚未独立验证。

首次选择内置 **Rounded shell**：

1. 点击右侧外墙的平面，确认标记为 **X+**。
2. 添加矩形开口：**Width 18 mm**、**Height 10 mm**、**Local Y position 32 mm**、**Local Z position 17 mm**、**Cut depth 5 mm**。
3. 应用开口，检查是否切穿 3 mm 厚的墙。
4. 在 Parameters 中把 `width` 从 **100 改为 140**，重新生成；开口应跟随右侧墙，局部 Y/Z 坐标保持不变。
5. 导出 SCAD 和 STL；需要继续编辑时，再保存工程。

该深度足以切穿本例的一面墙，不会到达对面墙。若选择贯穿切削，则会同时打开对面墙。

OpenSCAD 作为独立进程在本机运行；界面使用 Three.js，本机服务使用 Express，源程序分析使用 openscad-parser。首次安装需要联网获取依赖；模型源码和渲染都在本机服务中处理，无需账号或模型 API 密钥。

## 怎样验证与参与

运行源码、作用域、输入检查，以及真实 STL 流程：

```sh
npm test
node --import tsx scripts/check-workflow.ts
node --import tsx scripts/check-compound-workflow.ts
npm run build
```

这些检查实际编译几何，测量改尺寸后的材料移除量，并验证未选中的实例保持不变。输入包括长方体托盘、两个圆角凸包托盘，以及旋转后的拉伸轮廓。源码测试还检查凹形实体的盲孔不会误切更低的台阶。结果保存在 `.cache/workflow/` 和 `.cache/compound-workflow/`。

[外部模型记录](docs/imported-model.md)保留了圆角电子盒外墙开口成功、手机支架拉伸体未完成孔位选择，以及另一支架渲染超时的全部结果。成功修改的电子盒仍有原模型已有的网格缺陷。这些是工程检查，不代表可打印性、广泛兼容性或用户采用；陌生用户的完整首次体验仍待验证。

目前最有用的贡献是可以合法分享的单文件 SCAD 示例，并说明希望添加什么结构、需要在怎样的参数变化下继续成立。请同时提供模型许可和作者来源，不提交未经授权的私有模型。
